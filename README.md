# ЛЕСНОЙ | График кухни

Простой статический редактор недельного графика поваров. Работает без сервера, базы данных и регистрации.

Открыть сайт: https://99jrzwn8pb-droid.github.io/lesnoy-kitchen-/

## Как пользоваться

1. Добавьте сотрудников и укажите их цеха. Нажмите имя для изменения имени, телефона и цеха.
2. Выберите неделю календарём или стрелками. Даты отображаются автоматически.
3. Выберите смену в панели, затем нажимайте ячейки. Для своего времени включите «Редактировать ячейки». Варианты смен можно настроить.
4. Для повторения графика откройте следующую неделю и нажмите «Из прошлой недели».
5. Нажмите «Скачать PNG»: в изображение попадёт вся таблица. Телефоны можно скрыть. Для качества отправляйте PNG в Telegram как файл.
6. Периодически сохраняйте JSON через меню «Данные». Импорт резервной копии заменяет все текущие данные. Отдельный файл команды добавляет сотрудников и обновляет телефоны, сохраняя заполненный график.

На Mac доступны стрелки, Enter, Delete, F2, отмена через ⌘Z и вставка диапазона из Excel через ⌘V. На iPhone таблица прокручивается вбок, имена закреплены.

## Хранение данных

Сотрудники и графики сохраняются только в браузере на устройстве. Между Mac и iPhone, разными браузерами и разными адресами сайта данные не синхронизируются. Для переноса используйте JSON вручную. Очистка данных браузера удаляет график; храните резервные копии в личных файлах.

В репозитории нет персональных данных. Не загружайте сюда JSON-копии, исходные файлы и изображения с реальными телефонами. Данные, введённые через сайт, не отправляются в репозиторий или на сервер приложения.

Персональную команду можно добавить через **Данные → Импортировать JSON** или через личную ссылку импорта. Перед добавлением показывается список для проверки. При повторном импорте совпадающие по имени сотрудники сохраняют ID и свои смены; пустой телефон не стирает уже введённый. Личная ссылка содержит данные в части адреса после `#`: приложение обрабатывает её в браузере и сразу убирает из адресной строки. Личные файлы и ссылки не входят в публичную сборку.

## Запуск и публикация

Для локального запуска скачайте файлы вместе и откройте `index.html` в Safari или Chrome. Для постоянной работы используйте HTTPS-ссылку выше: хранение при открытии локальных файлов зависит от браузера.

GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**. Сборка и установка зависимостей не нужны. Публикуются только статические файлы.

Проверяйте сохранение и загрузку PNG на вашем iPhone перед постоянным использованием. Для точного совпадения с исходным Excel потребуется добавить ваш состав команды.
